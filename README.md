## Language-Translator
An end-to-end Neural Machine Translation web application powered by Meta's NLLB-200 (No Language Left Behind). Built with PyTorch and Streamlit, it supports real-time translation across **200+ languages**, focusing heavily on high-accuracy translations for low-resource languages.

Natural Language Processing application that breaks down language barriers by translating text across 200 different languages and scripts. At its core, the application uses Meta's state-of-the-art NLLB-200 (No Language Left Behind) distilled Transformer model. The user interface is built entirely in Python using Streamlit for rapid, interactive deployment.
